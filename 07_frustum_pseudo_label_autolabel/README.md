# 07 · 点云 3D 自动标注：视锥几何伪标签生成（KITTI）

**只有 2D 框、没有任何 3D 人工标注**时，能不能纯靠几何生成可训练的 3D 框？

## 管线
```
图像 → 2D 框 → KITTI 标定投影取视锥点云 → RANSAC 去地面 → DBSCAN 聚类
     → 拟合 3D 框 → KITTI label_2 格式伪标签 → 训 PointPillars → 对比全监督
```

**误差解耦设计**：先用 **GT 的 2D 框**跑管线，测出几何管线本身的上限；换零样本 2D 框后的差值即为 2D 检测器质量的代价。不这么拆，掉点时无法归因。

## 三处几何改进（v1 → v3，100 帧 / 204 个 Car 实测）

| 指标 | v1 最小外接矩形 | **v3** | 改进 |
|---|---|---|---|
| BEV IoU 中位 | 0.368 | **0.637** | +73% |
| BEV IoU 均值 | 0.396 | 0.567 | +43% |
| IoU>0.5 占比 | 36.9% | **66.2%** | +79% |
| IoU>0.7 占比 | 20.0% | **41.5%** | +108% |
| 出框率 | 95.6% | 95.6% | — |

1. **L-shape fitting**（Zhang et al. closeness 准则）替代最小面积矩形——视锥里只看得到车的一个面，最小外接矩形贴的是可见点云而非真实轮廓。*单独贡献：朝向中位 16.7°→9.8°。*
2. **类别先验尺寸 + 沿视线的中心补偿**——观测尺寸只是下界，用 KITTI 均值（Car h1.53 / w1.63 / l3.88）补齐，并沿视线把中心后推半个未观测车身。*单独贡献：尺寸偏差 l −0.71→+0.12。*
3. **90° 歧义消解**——只看单面时"跨度大"≠车长方向。判据：主可见面跨度更接近车宽(1.63m) 说明看到的是车头/车尾，长轴垂直于该面；更接近车长(3.88m) 则看到的是车侧。*单独贡献：IoU 中位 0.518→0.637。*

## 全量生成
train **3712 帧**，14357 个 GT 2D Car 框 → **12431 个 3D 伪标签（转化率 86.6%）**，耗时 **3.6 分钟**（16 核 / 14 进程）。
val 一律用真值，**评测不作弊**。

## 下游训练结果（KITTI val，AP_R40，Car IoU 0.70，80 epoch）

| 设定 | 3D Easy | 3D **Mod** | 3D Hard | BEV Easy | BEV **Mod** | BEV Hard |
|---|---|---|---|---|---|---|
| 视锥伪标签（**零 3D 人工标注**） | 19.30 | **16.44** | 13.51 | 60.07 | **54.14** | 43.75 |
| 真值 Car 单类（公平对照） | 87.80 | **77.70** | 73.56 | 92.14 | **88.00** | 86.65 |

> **关键发现：BEV AP 达到全监督的 62%，但严格 3D IoU 0.7 只剩 21%。**
> 说明几何管线能把**俯视足迹（位置+朝向）大致拟合对**，但**高度与精确 3D 范围不准**——
> 视锥里看不到车顶和背面，尺寸靠先验补，一旦用 IoU 0.7 的严格阈值就大量掉出。
> 这也解释了为什么弱监督 3D 检测文献普遍报 BEV 指标。

**范围控制（诚实）**：只做 **Car**。Pedestrian / Cyclist 点数太少、视锥聚类不稳定；KITTI 中 Car 占 84%，弱监督 3D 检测文献（FGR 等）也基本只报 Car。
