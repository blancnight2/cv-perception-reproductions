# 05 · BEV 多相机感知：训练期 LiDAR 深度监督消融（Lift-Splat-Shoot / nuScenes）

在 LSS 上加**训练期 LiDAR 深度监督**（BEVDepth 式深度分布交叉熵），回答两个问题：
**① 深度监督需要多稠密的 LiDAR？② 深度损失权重怎么定？**

> 口径说明：本项目是在官方 LSS（nv-tlabs）基础上做的**受控消融实验**，不是新方法。

## 我改了什么（自己写的部分）

| 文件 | 内容 |
|---|---|
| `code/src/depth_sup.py` | ego→cam→像素投影生成深度标签；**含数据增强对齐** `uv = uv @ post_rot.T + post_tran`；同格子取最近面（min-pool） |
| `code/src/beam_sub.py` | 按 `ring_index` 做**线数下采样**（`ring % (32/n) == 0`）。注意 nuScenes `.pcd.bin` 是 5 列，`LidarPointCloud.from_file` 会丢掉第 5 列 ring，必须自己读原始 buffer |
| `code/patch_lss.py` | 官方 `CamEncode.forward` **把深度分布算完就丢了**（只 `return x`）。4 处补丁把 depth 透传到 `LiftSplatShoot.forward`，默认行为不变 |
| `code/patch_partial_blobs.py` | 只下载部分 blob 时，取「split 场景 ∩ 磁盘上文件齐全的场景」交集 |
| `code/test_synth.py` | **17 项解析测试**（不依赖 nuScenes）：投影落点、min-pool、损失边界等，先验证再碰真数据 |

## 实验设定
- nuScenes 子集，训练/验证 **20576 / 3280 帧**；固定数据顺序、增强与超参，单变量对照。
- 设**种子重复档**量化噪声——不建立噪声基线，任何差异都无法判读。

## 结果一：线数稀疏度（深度权重 1.0）

| 激光线数 | BEV 分割 IoU | 相对无监督 | 深度 MAE (m) | bin 命中 |
|---|---|---|---|---|
| 0（无监督） | 0.3288 | — | 7.55 | 0.083 |
| 4 线 | 0.2797 | −14.9% | 4.96 | 0.197 |
| 8 线 | 0.2910 | −11.5% | 2.94 | 0.281 |
| 16 线 | 0.2970 | −9.7% | **2.04** | 0.351 |
| 32 线 | 0.2960 | −10.0% | **1.93** | 0.414 |

种子噪声下限 **0.0028**（32 线两个种子之差）。小于该值的差异不作结论。

> **发现：16 线即达 32 线 95% 的深度精度（2.04 vs 1.93 m），线数再翻倍收益极小。**
> 直接对应传感器选型——32 线 vs 128 线的成本权衡。

## 结果二：损失权重（32 线）

分割损失约 0.12、深度损失约 2.2，**量级差约 18 倍**——权重 1.0 其实是让深度项主导了训练。

| 配置 | 末 8 轮 IoU 均值±σ | 相对基线 | 深度 MAE (m) | 深度项/分割项 |
|---|---|---|---|---|
| 无深度监督（基线） | 0.3226 ± 0.0031 | — | 7.55 | — |
| 权重 0.05 | **0.3257 ± 0.0049** | +1.0% | 2.16 | ≈1× |
| 权重 0.20 | 0.3092 ± 0.0104 | −4.2% | 1.96 | ≈3.7× |
| 权重 1.00 | 0.2916 ± 0.0022 | −9.6% | 1.93 | ≈18× |

种子噪声下限 **0.0042**。最好的有监督档与基线相差 +0.0031，**仅为噪声的 0.7 倍**。

> **结论（诚实）：校准权重后，深度监督在该数据规模下既不明显帮助也不明显损害 BEV 分割**——
> 差异落入噪声，测不出显著增益。但深度 MAE 从 7.55 降到 2.16 m，深度分支确实学到了东西。
> 早期 −9.6% 的掉点不是「深度监督有害」，而是**权重没校准**导致的损失量级失衡。

## 复现
```bash
git clone https://github.com/nv-tlabs/lift-splat-shoot   # 上游
python code/test_synth.py            # 先跑 17 项解析测试
python code/patch_lss.py             # 打深度透传补丁
bash  code/run_ablation.sh           # 线数消融
```
