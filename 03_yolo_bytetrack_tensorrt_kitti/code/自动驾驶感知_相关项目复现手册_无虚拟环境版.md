## 2　【首选】2D 目标检测：YOLO on KITTI

### 2.1 先跑通推理（几分钟出框，验证环境）
```powershell
yolo detect predict model=yolo11n.pt source="https://ultralytics.com/images/bus.jpg" save=True
# 或对本地图片/文件夹：source=D:/imgs   结果存到 runs/detect/predict
```

### 2.2 数据：KITTI 2D 检测（转 YOLO 格式）
- 去 KITTI 官网下 object detection 的 `left color images(~12GB)` 与 `training labels`；解压得 `image_2/` + `label_2/`。
- KITTI 标签是像素框 `type ... x1 y1 x2 y2 ...`，YOLO 要归一化 `cx,cy,w,h` + 类别号 。用下面脚本转（常合并为 Car/Pedestrian/Cyclist 三类，DontCare 忽略）：

```python
import os, glob
CLS={"Car":0,"Van":0,"Truck":0,"Pedestrian":1,"Person_sitting":1,"Cyclist":2}  # 合并
W,H=1242,375   # KITTI 典型分辨率；建议逐图读真实尺寸更稳
for f in glob.glob("label_2/*.txt"):
    out=[]
    for ln in open(f):
        p=ln.split(); t=p[0]
        if t not in CLS: continue
        x1,y1,x2,y2=map(float,p[4:8])
        cx,cy=((x1+x2)/2/W),((y1+y2)/2/H); w,h=(x2-x1)/W,(y2-y1)/H
        out.append(f"{CLS[t]} {cx:.6f} {cy:.6f} {w:.6f} {h:.6f}")
    open("labels/"+os.path.basename(f),"w").write("\n".join(out))
```

再建 `kitti.yaml`：
```yaml
path: D:/datasets/kitti_yolo
train: images/train
val:   images/val
names: {0: Car, 1: Pedestrian, 2: Cyclist}
```
*嫌 KITTI 麻烦，可先用 ultralytics 自带小数据 data=VOC.yaml 或 coco8.yaml 跑通训练流程证明能力，再上 KITTI 增强 AD 相关性。*

### 2.3 训练 + 评估
```powershell
yolo detect train model=yolo11n.pt data=kitti.yaml epochs=50 imgsz=640 batch=16 device=0
yolo detect val   model=runs/detect/train/weights/best.pt data=kitti.yaml   # 出 mAP50 / mAP50-95
```
12GB 显存：batch 先 16，OOM 就降到 8；用 yolo11n/s(nano/small) 起步，够快够跑通 。看到 mAP 数字即成功。

**简历行（跑通后）**：YOLO(v8/11) KITTI 2D 车辆 / 行人 / 骑行检测复现——完成 KITTI→YOLO 数据转换与训练评估，mAP50 = 实测值；熟悉 anchor-free 检测头、正负样本分配与 mAP 评价。（个人复现）
**面试能聊**：one-stage vs two-stage、YOLO anchor-free 化、CIoU 损失、Mosaic 增强、mAP@0.5:0.95 怎么算。

## 3　【差异化】多目标跟踪：ByteTrack（ultralytics 内置）

ultralytics 内置 ByteTrack / BoT-SORT，检测器直接接跟踪，一条命令出带 ID 的跟踪视频——几乎零额外成本拿下"多目标跟踪"这个 JD 点。

```powershell
# 对一段行车视频做多目标跟踪（用你上一步训好的 best.pt 或官方 yolo11n.pt）      
yolo track model=yolo11n.pt source=drive.mp4 tracker=bytetrack.yaml save=True   
```
*找不到行车视频：KITTI tracking 子集或 nuScenes 的连续帧拼成视频即可；输出 runs/track/ 里每目标带稳定 ID，截图 / 存视频作证据。*

**简历行（跑通后）**：基于 YOLO + ByteTrack 复现多目标跟踪（tracking-by-detection） ，在行车视频上输出稳定轨迹 ID；理解卡尔曼预测 + 匈牙利匹配、ByteTrack 低分框二次关联抗遮挡。（个人复现）
**面试能聊**：SORT→DeepSORT(ReID)→ByteTrack 演进；ID switch / MOTA / IDF1 指标；遮挡怎么处理。

## 4　【补短板】部署优化：ONNX → TensorRT + INT8 量化

这条直接补你最大的短板（加分4：TensorRT / 量化 / 蒸馏），而且不用数据集——拿上一步的模型导出、测速即可。

### 4.1 装 TensorRT（Blackwell 需 10.x）
```powershell
pip install tensorrt                 # 需与 CUDA 版本匹配；Blackwell 用 TensorRT 10.x
python -c "import tensorrt as trt; print(trt.__version__)"
```

### 4.2 一键导出（ultralytics 直接 ONNX→TensorRT，支持 INT8）
```powershell
yolo export model=best.pt format=onnx                      # 先导 ONNX（最稳，一定成功）
yolo export model=best.pt format=engine half=True          # FP16 TensorRT 引擎 
yolo export model=best.pt format=engine int8=True data=kitti.yaml   # INT8（用 data 做校准）
```

### 4.3 测速对比（这就是你简历的"成果数字"）
```powershell
yolo val model=best.pt        data=kitti.yaml   # PyTorch FP32 基线：mAP + 速度 
yolo val model=best.engine    data=kitti.yaml   # TensorRT：看 mAP 掉多少、速度快多少
# 记录三档：FP32 / FP16 / INT8 的 推理延迟(ms) 与 FPS，以及 mAP 变化
```
*TensorRT 安装/版本匹配是这节唯一的坑；实在装不上，只做到 ONNX 导出 + 讲清量化/蒸馏原理也能写、也能聊。engine 成了就有"加速 X 倍 / mAP 掉 Y"的硬数字。*

**简历行（跑通后）**：将 YOLO 检测模型导出 ONNX → TensorRT，做 FP16 / INT8 量化部署，实测推理提速 ≈实测倍数、mAP 损失 <实测值；掌握 PTQ 量化校准与精度-速度权衡。（个人复现）
**面试能聊**：INT8 PTQ 校准原理、量化为何提速、知识蒸馏(teacher-student)一句话、算子融合 / TensorRT 做了什么。

## 5　【进阶·有坑】3D 目标检测：PointPillars（OpenPCDet, KITTI）

**诚实预警**：OpenPCDet / mmdet3d 要编译 CUDA 算子(iou3d_nms、spconv 等)，Blackwell(sm_120) 上大概率要源码 / 指定算力编，和 BEVDet 一个难度档。给它预留成块时间；跑不动就跳过，3D 原理会讲即可（PointPillars = 点云柱状化 → 2D CNN → 检测头）。    

### 5.1 步骤概要
```powershell
git clone https://github.com/open-mmlab/OpenPCDet.git
cd OpenPCDet

# sm_120 较新，若 pip 找不到对应 spconv，需自行源码编译 spconv        
pip install spconv-cu120  # 或尝试匹配的最新版本
pip install -r requirements.txt

set TORCH_CUDA_ARCH_LIST=12.0
python setup.py develop            # 编译 iou3d_nms 等 CUDA 算子（易卡在这）    

# KITTI 3D：下 velodyne 点云+calib+label，按 docs 转 info，再：
python tools/train.py --cfg_file tools/cfgs/kitti_models/pointpillars.yaml      
```

**简历行（若跑通）**：复现 PointPillars 于 KITTI 点云 3D 目标检测，跑通训练/评估，3D mAP = 实测值；理解 pillar 编码 + BEV 2D 检测思路。（个人复现）
**面试能聊**：PointPillars vs VoxelNet(体素+3D稀疏卷积) vs 点法；为什么柱状化能加速；BEV 上做检测。
